# XY Mode (X-Y 파형 표시)
1. Osciloscope는 기본 Y-T(Time-Voltage) 모드 외에 XY Mode를 지원해야 한다.
   - Y-T Mode : X축은 시간, Y축은 전압으로 표시.
   - XY Mode : X축은 CH1 전압, Y축은 CH2 전압으로 표시.
2. Y-T / XY Mode 간 전환 기능을 지원한다.
3. XY Mode에서는 동일한 Simulation Timestamp에서 측정한 CH1, CH2 전압을 하나의 좌표 (X, Y)로 표시한다.
4. 두 채널의 신호를 시간 순서대로 연결하여 궤적을 표시한다.
5. XY Mode에서도 각 축의 Volt/Div 및 Position(Offset)을 독립적으로 설정할 수 있어야 한다.
6. XY Mode에서 다음 표시 방식을 지원한다.
   - Line : 연속된 측정 좌표를 선으로 연결.
   - Dot : 측정 좌표를 점으로 표시.
   - Persistence : 이전 측정 좌표의 궤적을 일정 시간 유지하거나 누적 표시.
7. XY Mode에서도 Run / Stop 및 Zoom 기능을 지원한다.
8. XY Mode에서는 일반 Y-T Mode의 Time/Div 및 Edge Trigger 기능을 비활성화한다. 단, 내부 신호 획득은 기존 Simulation Clock에 따라 수행한다.
9. XY Mode에서도 CH1, CH2에 설정된 Probe, Filter, Coupling 등의 신호 처리 설정이 동일하게 적용되어야 한다.
10. XY Mode에서는 두 채널의 전압 관계를 명확히 확인할 수 있도록 X/Y축의 전압 눈금과 0V 기준선을 표시한다.
11. XY Mode에서도 획득한 파형의 CSV 저장을 지원한다.
    - Timestamp
    - CH1 Voltage (X)
    - CH2 Voltage (Y)
12. 두 채널 중 하나라도 Probe가 연결되지 않았거나 비활성화된 경우, XY Mode의 파형 표시를 중단하고 해당 상태를 GUI에 표시한다.

## 추가 명시
### XY Mode는 두 신호를 각각 그리는 기능이 아니라, 동일 시점의 두 채널 전압을 하나의 좌표로 변환하여 표시하는 기능으로, CH1과 CH2의 샘플링 시점을 일치시켜야 한다.
